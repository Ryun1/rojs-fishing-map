# CLAUDE.md

Static PWA, no build step or dependencies. Code lives in `index.html` (HTML + CSS + JS + tide calculation from TICON-4 constants for Horta, between the `TIDE START` and `TIDE END` comments). Reference data lives in `data/`: `spots.json` (spot positions, facings, open and channel sectors, wave sample points, and the fishability limits) and `species.json` (its `season` arrays are generated by `tools/season.py` from the SREA landings in `docs/research/data/srea/`; rerun it rather than editing them by hand), and `sst-normal.json` (normal sea temperature by day of year, generated by `tools/sst_normal.py`). The island map is inline SVG in `index.html`; see `tools/map.md`.

- Run: `python3 -m http.server 8000` and open http://localhost:8000.
- Whenever any shipped file changes, bump `CACHE` in `sw.js`; new assets must also be added to its `FILES` list.
- Keep the theme tokens on `:root` with the dark-mode overrides in sync (both the `prefers-color-scheme` block and `[data-theme="dark"]`).
- Fish photos in `img/` must have EXIF/GPS metadata stripped before committing.
- Tests run by opening the app with `?test` (see `tests/README.md`); new features should add tests there.
